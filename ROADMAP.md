# NetworkPlugin — план развития

Актуализировано 28.11.2026. Публичный самостоятельный плагин AppShelf API v1.
Номера версий и выпуск не привязаны к версиям ядра.

## Принятая база 1.0.3

- [x] Самостоятельная сборка, сетевые проверки, три индикатора, IPC и резервирование.
- [x] WPF-окна в стиле AppShelf и встроенная многоразмерная иконка глобуса.
- [x] Источник обновлений GitHub и workflow отдельно подтверждаемых стабильных/предварительных релизов.

## Интеграция 1.1.0 — Preview

- [x] Один плагин, EXE, манифест и процесс; без изменений ядра AppShelf.
- [x] Общее окно настроек с отдельным разделом VPN.
- [x] VPN выключен по умолчанию; полное отключение его опроса, диагностики и действий.
- [x] Выбор обнаруженных адаптеров по Windows ID и программ по полному пути EXE.
- [x] Общая диагностика без повторных секций DNS, прокси и доступности.
- [x] Отдельно опциональный четвёртый индикатор VPN/TUN с различением неоднозначности и неподтверждённого маршрута.
- [x] Пошаговое восстановление с подтверждением каждого изменения, UAC, проверками объектов и консервативным фильтром прокси.
- [x] Совместимость с настройками 1.0.3, прежними индикаторами, резервированием и источником обновлений.
- [x] Исправление повторной сборки и регрессия двух сборок в один каталог.
- [x] Локальные автоматические проверки восстановления на тестовых подменах и WPF-проверки настроек.
- [x] Проверки настоящего EXE с VPN выключенным и включённым: окна, иконки, три размера, прокрутка, отсутствие дублирования отчёта и отказ от восстановления.
- [x] Локальное обновление 1.0.3 → 1.1.0 через настоящий runtime/хранилище пакетов, архив предыдущей версии и восстановление данных.
